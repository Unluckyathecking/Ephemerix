Can we find a dwarf planet without its coordinates?

Given no positions, our search picks out Haumea, Makemake and Eris, each the strongest signal in its field: a validation, not a discovery. Run on the real sky and backwards, it finds about as many peaks either way: nothing new above the noise.

How faint an object can we find?

We hid simulated moving objects of known brightness in the real images and counted how many the search found again. Brightness is in microjanskys (µJy), a unit of light received: smaller is fainter.

How to read this plot

Each point is one brightness bin of planted bodies: the fraction the search found again at the right position and rate. The thick line pools all twelve fields, with its 95% (Wilson) interval shaded; the thin lines are single fields. The dashed lines mark 50% and 90% recovery. Flux is at 1 µm for a body that reflects sunlight; hover a limit marker for its V magnitude, which assumes solar colours. Red lines are the two control fields.

The 50% and 90% limits are interpolated in these same eight bins. With finer bins the 90% point moves by a few µJy (97 to 106 µJy), which is the size of its uncertainty.

How we worked this out

What the search does

A distant object can be too faint to see in a single exposure. If we line up several images along its path, its light adds up. The trick is that we don’t know the path in advance.

We start with a patch of sky 20 arcminutes across, subtract images taken months earlier, and try thousands of paths through the remaining images. Each path represents a possible motion for an object 30 to 1000 astronomical units from the Sun during one SPHEREx pass of up to 16 days.

We run the search backwards along those paths to estimate how often noise and image artefacts produce peaks. Then we add simulated objects of known brightness to the real images and count how many we find again.

One astronomical unit (au) is the distance from Earth to the Sun. S/N, the signal-to-noise ratio, says how many times a peak stands above the noise. The backwards run is our null search: no real object moves that way, so whatever it finds is noise.
